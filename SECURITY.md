# Security Policy

## Supported Versions

Only the latest version of the API documentation and integration examples is supported.

## Reporting a Vulnerability

We take security seriously. If you discover any security issues with our API services, please DO NOT open a public issue. Instead, report it directly.

**IMPORTANT SECURITY RULES FOR DEVELOPERS:**
* Never commit your `X-RapidAPI-Key` or any other credentials to public repositories.
* Always use environment variables or secret managers to load your API keys.
* If you accidently commit a key, rotate it immediately in the RapidAPI Dashboard.
