# Authentication

This API is hosted on the RapidAPI Marketplace. All authentication goes through the RapidAPI Gateway.

## Headers Required

1. **X-RapidAPI-Key**: Your unique API Subscription Key. Get this by subscribing on the RapidAPI panel.
2. **X-RapidAPI-Host**: `tiktok-scraper-fast-stable1.p.rapidapi.com`

Never commit your `X-RapidAPI-Key` to public repositories. Use environment variables to protect your credentials.
